# 🐍 Python Learning

A structured collection of my Python learning journey, covering Python fundamentals, programming concepts, problem-solving, and practical exercises.

This repository documents my progress from **Python basics to data-oriented programming**, with examples and hands-on practice.

## 🎯 Purpose

The goal of this repository is to build a strong foundation in Python before moving into libraries and technologies used in **Data Science, Artificial Intelligence, Machine Learning, and Backend Development**.

The repository focuses on learning Python through:

* Concept-based practice
* Small programming exercises
* Hands-on examples
* Problem-solving
* Experimentation with Python syntax and features

## ▶️ Getting Started

Clone the repository:

```bash
git clone https://github.com/AuraHamza/python-learning.git
```

Navigate into the project:

```bash
cd python-learning
```

Run a Python file:

```bash
python filename.py
```

For Jupyter Notebook:

```bash
jupyter notebook
```
